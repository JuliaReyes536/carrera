Carrera de la Muerte.

La aplicación de carreras a pie utiliza React y una API con SQLite. Iníciala desde la terminal de Visual Studio Code, en la carpeta de este proyecto: 

npm install
npm run dev
Abrir control de carreras

En el primer acceso crea tu cuenta de administrador. También puedes ejecutar npm run demo para explorar datos ficticios en memoria en el puerto 5174.
